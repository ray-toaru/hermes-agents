# v2.10 Production Lock Acquire/Preserve Skeleton

## Status

v2.10 adds a **disabled, non-mutating production lock acquire/preserve skeleton**. It emits evidence for future acquire or preserve decisions, but it does not write lock files, acquire production locks, release production locks, enable real apply, mutate profiles, execute rollback, create production audit records, read secret values, mutate runtime state, or orchestrate business work.

`hermes-agentops apply` remains disabled and must continue to return non-zero.

## Added Artifacts

- `scripts/run-production-lock-lifecycle-skeleton`
- `scripts/check-production-lock-skeleton-run`
- `schemas/production-lock-skeleton-run.schema.json`
- `docs/examples/production-lock-skeleton-run.yaml`
- `tests/test_production_lock_skeleton_run.py`

## Behavior

The runner validates the v2.9 production lock lifecycle contract, then emits one of these non-authorizing statuses:

- `would_acquire_not_executed`
- `would_preserve_not_released`
- `failed_closed`

Even for a successful acquire skeleton run, all production side-effect flags remain false:

```yaml
lock_acquired: false
lock_released: false
production_lock_written: false
release_attempted: false
mutation_enabled: false
apply_authorized: false
```

## Attack Review

### Attack: Treat `would_acquire_not_executed` as a real acquired lock

Rejected. The schema and checker require `lock_acquired: false` and `production_lock_written: false`.

### Attack: Use preserve mode to release or clear a recovery lock

Rejected. Preserve mode targets `preserved_for_review`, requires manual review, and requires `lock_released: false`.

### Attack: Bypass the v2.9 lifecycle contract

Rejected. The checker validates the referenced lifecycle contract and verifies the contract hash binding.

### Attack: Use skeleton evidence to authorize apply

Rejected. The schema requires `apply_authorized: false`; the checker also verifies that `hermes-agentops apply` still fails closed.

## Result

The next safe slice remains non-mutating: production audit capture contract or rollback execution design/prototype. Real apply remains blocked.
